

# Автоматическая установка GitLab с использованием Docker и SSL-сертификатов

Этот проект предназначен для автоматической установки GitLab на сервере с использованием Docker. Скрипт настраивает SSL-сертификаты с помощью Certbot, поддерживает работу с доменами третьего уровня и позволяет настраивать кастомные порты для HTTP, HTTPS и SSH.

## Особенности

- **Простая установка**: Автоматическая настройка Docker и Docker Compose.
- **SSL-сертификаты**: Генерация и настройка сертификатов с использованием Certbot.
- **Поддержка доменов третьего уровня**: Вы можете использовать поддомены (например, `gitlab.example.com`) или основное доменное имя.
- **Гибкость конфигурации портов**: Поддержка стандартных и кастомных портов для HTTP, HTTPS и SSH.

## Требования

1. **Операционная система**: Ubuntu (рекомендуется, но может работать и на других дистрибутивах).
2. **Свободный порт 80**: Обязательно для работы Certbot.
3. **DNS-настройки для поддомена**: Если вы собираетесь выносить GitLab на поддомен, необходимо настроить A-запись для вашего сервера. Пример:
   ```
   gitlab.example.com -> 192.168.1.1
   ```

Если вы используете основной домен (например, `example.com`), дополнительная настройка DNS не требуется, если домен уже направлен на ваш сервер.


## Как использовать

### 1. Клонирование репозитория
Скачайте или клонируйте репозиторий:
```bash
git clone https://github.com/kitaraw/gitlab-subdomain-docker-setup.git
cd install-gitlab
```

### 2. Подготовка сервера
- Убедитесь, что порт 80 свободен и сервер имеет публичный IP.
- Обновите систему:
  ```bash
  sudo apt update && sudo apt upgrade -y
  ```

### 3. Запуск скрипта установки
Запустите установочный скрипт:
```bash
sudo ./install-gitlab.sh
```

### 4. Настройка параметров
- Укажите доменное имя (например, `gitlab.example.com`).
- Выберите, хотите ли использовать стандартные порты или задать свои.

### 5. Результат
- GitLab будет доступен по адресу:
  ```
  https://gitlab.example.com
  ```

## Параметры конфигурации

- **Имя домена**: Вы указываете во время выполнения скрипта.
- **Порты**:
  - Стандартные: `80` (HTTP), `443` (HTTPS), `22` (SSH).
  - Кастомные: Задаются пользователем. Например:
    - HTTP: `8080`
    - HTTPS: `8443`
    - SSH: `2222`

> **Важно:** Для выпуска SSL-сертификатов Certbot требуется порт 80.

## Пример использования

1. **Настройте DNS**: 
   Добавьте A-запись:
   ```
   gitlab.example.com -> 192.168.1.1
   ```

2. **Запустите установку**:
   ```bash
   sudo ./install-gitlab.sh
   ```
   Введите:
   ```
   Имя домена: gitlab.example.com
   HTTP порт: 8080
   HTTPS порт: 8443
   SSH порт: 2222
   ```

3. **Доступ**:
   После завершения настройки GitLab будет доступен по адресу:
   ```
   https://gitlab.example.com
   ```

## Дополнительные рекомендации

- **Проверка Docker и Docker Compose**:
  Убедитесь, что Docker и Docker Compose установлены и настроены корректно.
  ```bash
  docker --version
  docker-compose --version
  ```

- **Управление Docker-контейнером**:
  - Запуск: `docker-compose up -d`
  - Остановка: `docker-compose down`
  - Перезапуск: `docker-compose restart`

- **Сертификаты SSL**:
  Сертификаты генерируются с помощью Certbot и копируются в директорию `ssl`.

## Примечания

- **Поддомены**: Вы можете использовать домен третьего уровня (`gitlab.example.com`) или основной домен (`example.com`). Убедитесь, что DNS настроен корректно.
- **Кастомные порты**: При использовании нестандартных портов необходимо убедиться, что они доступны извне.
- **Первый запуск**: Поднятие контейнера GitLab может занять более 5 минут.
