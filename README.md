

# Установка GitLab с использованием Docker и SSL-сертификатов

Этот проект автоматизирует установку GitLab на сервере с использованием Docker и настроенных SSL-сертификатов от Certbot. Скрипт поддерживает как стандартные, так и пользовательские порты, а также работу с доменами третьего уровня.

## Возможности

- **Быстрая настройка**: Установка и настройка Docker и Docker Compose.
- **Автоматические SSL-сертификаты**: Генерация сертификатов для указанного домена.
- **Гибкость конфигурации**: Поддержка стандартных и пользовательских портов.

## Требования

- **Операционная система**: Ubuntu (рекомендуется).
- **Свободный порт 80**: Необходим для работы Certbot.
- **DNS-настройка**: Домен должен быть направлен на IP вашего сервера (например, через A-запись).

## Установка

### 1. Подготовка сервера

1. Убедитесь, что порт 80 свободен и DNS-домен настроен:
   ```
   gitlab.example.com -> 192.168.1.1
   ```
2. Обновите систему:
   ```bash
   sudo apt update && sudo apt upgrade -y
   ```

### 2. Клонирование репозитория

Скачайте репозиторий:
```bash
git clone https://github.com/kitaraw/gitlab-subdomain-docker-setup.git
cd gitlab-subdomain-docker-setup
```

### 3. Запуск установочного скрипта

Запустите скрипт:
```bash
sudo ./install-gitlab.sh
```

Следуйте инструкциям:
- Укажите домен (например, `gitlab.example.com`).
- Выберите стандартные или пользовательские порты.

### 4. Проверка выпуска SSL-сертификата

В процессе генерации SSL-сертификатов Certbot запросит данные для проверки домена. Это включает:
- Подтверждение владения доменом (через HTTP- или DNS-верификацию).
- Обеспечение доступности порта 80 для автоматической проверки.

Если данные для проверки введены корректно и домен настроен правильно, сертификаты будут успешно сгенерированы.

### 5. Результат

После завершения настройки GitLab будет доступен по адресу:
```
https://gitlab.example.com
```

> **Примечание:** Первый запуск может занять более 5 минут.

## Управление Docker-контейнерами

- Запуск: `docker-compose up -d`
- Остановка: `docker-compose down`
- Перезапуск: `docker-compose restart`

## Параметры конфигурации

- **Имя домена**: Указывается при установке.
- **Порты**:
  - Стандартные: `80` (HTTP), `443` (HTTPS), `22` (SSH).
  - Кастомные: Например, `8080` (HTTP), `8443` (HTTPS), `2222` (SSH).

## Примечания

1. **Certbot и порт 80**:
   Порт 80 должен быть свободен во время генерации SSL-сертификатов.
2. **Запрос данных Certbot**:
   Certbot запросит необходимые данные для проверки права владения доменом.
3. **Долгий первый запуск**:
   Поднятие контейнера GitLab может занять несколько минут.
4. **SSL-сертификаты**:
   Генерируются с помощью Certbot и копируются в директорию `ssl`.
